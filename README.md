# Proyecto Fundamentos Básicos de Python – Casos COVID-19 (datos.gov.co)

Aplicación de consola modular que consulta la API de Datos Abiertos
(dataset `gt2j-8ykr`) y muestra Ciudad, Departamento, Edad, Tipo, Estado y País de procedencia.

## Estructura
- `main.py`: punto de entrada
- `api/`: módulo que consulta la API
- `ui/`: módulo de interfaz por consola

## Ejecución
```
python -m venv venv
venv\Scripts\activate        # Windows  (Linux/Mac: source venv/bin/activate)
pip install -r requirements.txt
python main.py
```
